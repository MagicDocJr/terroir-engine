# PROTOTYPE — First-pass UI (throwaway)

**Question it answers:** what should the Football Manager-style management layer look and feel like, in Godot's own UI (no web view), at WSET Level 3 depth?

Every screen in `docs/spec.md` §8.1 is built and clickable, plus the pre-game flow. The data is fake but plausible (`data/fake_data.json`, generated by `make_data.py`); nothing is simulated. The scenario date is **Mon 20 Oct 2025**, so every screen has content: Blocks A–D are harvested and fermenting, and Block E is still hanging with noble rot starting.

## Run

```bash
./run.sh                      # opens on the pre-game Region picker
./run.sh --screen ripeness    # jump straight to a screen
./shot.sh                     # capture every screen at 1920×1080 into shots/
./shot.sh --only inbox,plot   # capture some screens only
python3 make_data.py          # regenerate the fake data
python3 fetch_fonts.py        # re-download the fonts (already committed)
```

This needs the Godot 4.7.2 .NET build (see the path in `run.sh`). The UI itself is GDScript only.

## Keys and mouse

| Input | Does |
|---|---|
| Click the left menu, or keys **1–9, 0** | Inbox, Estate, Plot & Blocks, Weather, Programmes, Ripeness, Winery, Blending, Wines, Glossary |
| **P** | Back to the pre-game flow (Region → Plot comparison → Buy) |
| **Space**, **+1 day**, **+1 week**, **Continue** | Time controls. In the prototype these only show a toast; the data doesn't change |
| **Tab** | Would open the 3D walkaround (not part of this prototype) |
| Hover | Tooltips on table cells, chart crosshairs, forecast days, ratings |
| Click | Sort the Block table, select Blocks, Lots and Wines, pick Programme tiers, change cellar choices, step blend shares, search the Glossary |

## Screens (`shots/`)

1. `01_region`: choose a Region: climate, soils, wine law, land price, hazards, typical wines, how the 4 Varieties would do, monthly climate
2. `02_plots`: compare 4 Mosel Plots: 1–20 attribute ratings (Football Manager style), facts, Variety suitability, a Mentor comment per Plot, Buy
3. `03_inbox`: Alerts and messages; reading pane with a "Why?" explanation and decision buttons
4. `04_estate`: cash-flow chart, P&L against budget, projected wine revenue, staff with Staff levels and 1–20 attributes
5. `05_plot`: sortable Block table (hover for detail), a clickable schematic Plot map, Block facts, soil profile
6. `06_weather`: season indices vs normal, vine-stage timeline, heat accumulation, rain vs normal, disease-risk small multiples, 7-day forecast with "What it means"
7. `07_programmes`: Low/Medium/High tiers with cost, labour, effect and disease-pressure change; season totals and labour capacity update live
8. `08_ripeness`: °Oe with Prädikat bands and projections, TA and pH (separate charts), harvest planner with a 7-day pick calendar for Block E
9. `09_winery`: Lots with status and sparklines; fermentation and temperature curves; cellar choices (dropdowns) with "Why?" explanations
10. `10_blending`: shares of each Lot per Wine (steps of 20 %); each Wine's volume, bottles, alcohol, sugar, TA, pH, style and qualifying level update live
11. `11_wines`: Tasting sheet (appearance, nose, palate, conclusions), each descriptor with its cause; analysis, Legal category, price
12. `12_glossary`: game terms (CONTEXT.md) and wine terms, searchable

## Design choices (for review)

- **Look: "Mosel slate and chalk".**
  - Slate blue-grey surfaces and chalk-coloured text.
  - Riesling gold is used *only* for primary actions and the current selection.
  - Barlow Semi Condensed (headings, numbers) gives the dense Football Manager feel, and Inter is used for reading text. Both fonts are OFL and are shipped in `fonts/`, so nothing depends on Windows fonts.
- **Block colours** are the validated categorical palette from the dataviz skill (dark mode, passes the colour-blind check). A Block is never shown by colour alone: its letter is always there.
- **Charts:**
  - one measure per chart (no dual axes, so °Oe, TA and pH are separate)
  - 2 px lines, a recessive grid, labels at the end of each line, and a crosshair tooltip
  - disease risk as small multiples, so no colour competes with the Block colours
- **Status** is always an icon plus a word plus a colour (● good, ▲ watch or serious).

## Questions for the owner's morning review

1. **Theme.** Is the dark slate-and-chalk look right, or would you prefer something lighter and more like paper? Is gold-only-for-actions clear?
2. **Density.** Is this the right amount of information per screen, and is the text readable on your monitor? Body text is 16 px at 1920×1080.
3. **Navigation.** Ten screens in the left menu. Should Blending and Wines merge into Winery, or Weather into Plot & Blocks?
4. **1–20 ratings.** Does the Football Manager-style rating grid (Plot comparison, staff attributes) help, or would raw numbers be clearer?
5. **Tasting sheet.** Is the two-column "Assessment / Because" layout the right teaching format? Should "Because" start hidden and be revealed on click, which would make an exam mode easy later?
6. **Inbox decisions.** Are decisions inline with a "Why?" explanation right? Should the Mentor have a portrait or more character?
7. **Programmes.** Is Low/Medium/High enough for the MVP? Is "disease pressure +18 %" understandable, or would words be better ("more infections in wet spells")?
8. **Units.** °Oe is the main unit for the Mosel, with °Brix in tooltips. Should Napa switch to °Brix as the main unit?
9. **Time controls.** Is the top-right placement right, and is the automatic stop on Alerts clear?
10. **Glossary.** Would you like every game term to show its definition on hover anywhere in the UI?

## Known limitations (prototype)

- All numbers are fake. They're plausible but not yet checked against `docs/science/`. The glossary wording is a draft.
- The time controls, decisions, hiring and "Buy" only show a toast.
- Only the Mosel Plots and Wine 2's Tasting sheet are built.
- The capture shots show a demo tooltip on a few charts, to show what hover looks like.
- Red-variety Prädikat minimums are marked UNVERIFIED (Lot D).
