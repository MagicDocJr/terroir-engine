# Tasks in 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staff hand the player dated tasks (winter pruning, leaf removal, green harvest, cap management) that the player does on a demonstration vine or tank in the 3D world, or leaves to the crew.

**Architecture:** The simulation owns `FieldTask`s (opened in `StepDay`, closed by a command, the dashboard or the due date) and publishes them in the snapshot; every option maps onto a setting that already exists, so outcomes are unchanged when the player does nothing. The Godot 3D view adds markers, an E-to-interact close-up with clickable parts, and a signal the shell turns into the `task` command; the crew figures follow the task's crew window.

**Tech Stack:** C# (.NET 8 core, .NET 10 xUnit), Godot 4.7.2 .NET + GDScript, WSL build scripts.

**Spec:** `docs/superpowers/specs/2026-09-28-tasks-in-3d-design.md`

## Global Constraints

- ADR 0001: the UI never computes outcomes; options and their explanations come from the snapshot.
- Doing nothing reproduces today's game: every existing test passes unchanged; the plan of every task is the current setting.
- Save format unchanged (setup + commands); replay reproduces tasks.
- Player-facing words follow `CONTEXT.md` (Vintage, Block, Lot; new term **Task**).
- Timing windows and crew days are labelled "Game simplification" and `UNVERIFIED` in the science docs.
- Build C# with `scripts/build-game.sh` (WSL dotnet); sim tests `cd sim && ~/.dotnet/dotnet test -v q`; UI checks `scripts/fuzz.sh`, `scripts/capture.sh`, 3D `scripts/godot.sh res://src/view3d/view3d_test.tscn -- --tasktest`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`; no push.

## Review Focus

1. **A setting changed on the dashboard after its task was already decided** → no second completion, no error; the latest setting stands. Pinned in Task 1 (`DashboardChange_AfterDecision_JustChangesTheSetting`).
2. **A Block harvested before its green-harvest task is due** → the task closes with the plan at harvest, no thinning is applied to picked fruit. Pinned in Task 1 (`GreenHarvest_ClosesAtHarvest`).
3. **A white Lot fermenting** → no cap-management task. Pinned in Task 1 (`CapManagement_OnlyForRedLots`).
4. **E pressed with no task in reach, or with the drone camera on** → nothing happens. Pinned in Task 4 (harness step `no_task_no_closeup`).
5. **The 3D view closed (Tab) while in a close-up** → the close-up ends, the mouse is freed, no command is sent. Pinned in Task 4 (harness step `tab_leaves_closeup`).

```csharp
namespace TerroirEngine.Game;

public enum TaskKind { Prune, LeafRemoval, GreenHarvest, CapManagement }
public enum TaskStatus { Open, Done, Delegated, Planned }

/// <summary>A dated job from the staff (CONTEXT.md: Task): the player does it on a demonstration vine or tank in 3D, decides it on the
/// dashboard, or lets the crew do it to the staff member's plan. Every option maps onto an existing setting (tasks-in-3d design §3).</summary>
public sealed class FieldTask
{
    public int Id { get; init; }
    public TaskKind Kind { get; init; }
    public string BlockId { get; init; } = "";
    public string LotId { get; init; } = "";
    public DateOnly Opened { get; init; }
    public DateOnly Due { get; init; }
    public TaskStatus Status { get; set; } = TaskStatus.Open;
    public string Choice { get; set; } = "";
    public string Timing { get; set; } = "";
    public string DecidedBy { get; set; } = "";
    public DateOnly? Decided { get; set; }
    public DateOnly? CrewUntil { get; set; }
    public bool CrewActive(DateOnly today) => CrewUntil != null && Decided != null && today >= Decided && today <= CrewUntil;
}

/// <summary>Player-facing words and options for each task kind. Explanations restate cited facts (canopy-and-yield.md, extraction-and-oak.md).</summary>
public static class TaskCatalog
{
    public sealed record Option(string Value, string Label, string Why);

    public static string Title(TaskKind k) => k switch { TaskKind.Prune => "Winter pruning", TaskKind.LeafRemoval => "Leaf removal", TaskKind.GreenHarvest => "Green harvest", _ => "Cap management" };
    public static string Verb(TaskKind k) => k switch { TaskKind.Prune => "prune this vine", TaskKind.LeafRemoval => "pull leaves on this vine", TaskKind.GreenHarvest => "thin this vine", _ => "work the cap" };
    public static string Where(TaskKind k) => k == TaskKind.CapManagement ? "hall" : "vineyard";
    /// <summary>Hours per hectare for the crew to finish the Block after the decision (visual only; UNVERIFIED design values).</summary>
    public static double CrewHoursPerHa(TaskKind k) => k switch { TaskKind.Prune => 80, TaskKind.LeafRemoval => 40, TaskKind.GreenHarvest => 30, _ => 0 };

    public static IReadOnlyList<Option> Options(TaskKind k) => k switch
    {
        TaskKind.Prune => new Option[]
        {
            new("Low", "Short cane · 6 buds per m²", "Fewer buds, fewer bunches: a smaller crop that ripens more fully and concentrates more. Burgundy growers prune short to stay inside the yield limits."),
            new("Balanced", "Medium cane · 8 buds per m²", "The usual compromise between crop size and ripeness."),
            new("High", "Long cane · 11 buds per m²", "A big crop. Over about 1 kg of fruit per m² of leaf area it ripens slowly and can taste diluted (Kliewer & Dokoozlian 2005)."),
        },
        TaskKind.LeafRemoval => new Option[]
        {
            new("Morning", "Morning side", "Opens the bunches to the gentle morning sun: they dry faster after dew and rain (less rot) without the afternoon heat that burns berries."),
            new("Afternoon", "Afternoon side", "More light and warmth on the fruit, but exposed bunches can pass 46 °C at the berry surface on hot afternoons and sunburn."),
            new("Both", "Both sides", "The most open fruit zone: driest bunches, most colour and aroma precursors, the highest sunburn risk."),
            new("None", "Leave the leaves", "A shaded fruit zone: fresher, greener flavours, more rot risk in wet years."),
        },
        TaskKind.GreenHarvest => new Option[]
        {
            new("0", "Keep every bunch", "The full crop stays on the vine."),
            new("1", "Drop about a fifth", "Cutting bunches at véraison lowers the yield and raises the leaf-area-to-fruit ratio: the rest ripens faster and more completely (Kliewer & Dokoozlian 2005)."),
            new("2", "Drop about two fifths", "A strong green harvest: the lowest yield, the most concentration. Also spares the vine's reserves for next year."),
        },
        _ => new Option[]
        {
            new("0", "Pump-over 2×/day", "Gentle: juice from the bottom is sprayed over the cap, which also aerates the yeast."),
            new("1", "Punch-down 2×/day", "Pushing the cap into the juice extracts more colour and tannin from the skins: traditional for Pinot Noir."),
            new("2", "Délestage + pump-over", "Draining the tank and pouring the juice back over the cap extracts strongly and removes some seeds (less harsh seed tannin)."),
            new("3", "Gentle, 1×/day", "The lightest extraction: a paler, softer wine."),
        },
    };

    public static string Label(TaskKind k, string value) => Options(k).FirstOrDefault(o => o.Value == value)?.Label ?? value;
}
```

```csharp
using TerroirEngine.Util;
using TerroirEngine.Vineyard;
using TerroirEngine.Winery;

namespace TerroirEngine.Game;

public sealed partial class GameSession
{
    public List<FieldTask> Tasks { get; } = new();
    private int _taskId;

    /// <summary>The staff member's plan for a task: the current setting (so an ignored task changes nothing).</summary>
    public string TaskPlan(FieldTask t)
    {
        var b = Blocks.FirstOrDefault(x => x.Data.Id == t.BlockId);
        return t.Kind switch
        {
            TaskKind.Prune => b!.BudLoad.ToString(),
            TaskKind.LeafRemoval => b!.LeafSide.ToString(),
            TaskKind.GreenHarvest => b!.CropThinning.ToString(),
            _ => (Lots.FirstOrDefault(l => l.Id == t.LotId)?.Choices["Cap management"] ?? 0).ToString(),
        };
    }

    private FieldTask OpenTask(TaskKind kind, string blockId, string lotId, DateOnly due)
    {
        var t = new FieldTask { Id = ++_taskId, Kind = kind, BlockId = blockId, LotId = lotId, Opened = Date, Due = due };
        Tasks.Add(t);
        return t;
    }

    /// <summary>Opens the pruning tasks of the current Vintage (15 January; the first Vintage's at game start).</summary>
    private void OpenPruningTasks()
    {
        var due = new DateOnly(Date.Year, 3, 1);
        var opened = Blocks.Select(b => OpenTask(TaskKind.Prune, b.Data.Id, "", due)).ToList();
        PostTaskMessage(TaskKind.Prune, opened);
    }

    /// <summary>Daily: open tasks whose moment has come, close tasks whose due date (or event) has passed.</summary>
    private void UpdateTasks()
    {
        if (Phase != GamePhase.Running) return;
        if (Date.Month == 1 && Date.Day == 15 && Date.Year > FirstVintage && Gate($"tasks-prune-{Date.Year}")) OpenPruningTasks();
        var newLeaf = new List<FieldTask>(); var newThin = new List<FieldTask>(); var newCap = new List<FieldTask>();
        foreach (var b in Blocks)
        {
            if (b.FruitSet == Date && !Tasks.Any(t => t.Kind == TaskKind.LeafRemoval && t.BlockId == b.Data.Id && t.Opened.Year == Date.Year))
                newLeaf.Add(OpenTaskOn(TaskKind.LeafRemoval, b.Data.Id, "", b.FruitSet.Value, b.FruitSet.Value.AddDays(25)));
            if (b.Veraison == Date && !b.Harvested && !Tasks.Any(t => t.Kind == TaskKind.GreenHarvest && t.BlockId == b.Data.Id && t.Opened.Year == Date.Year))
                newThin.Add(OpenTaskOn(TaskKind.GreenHarvest, b.Data.Id, "", b.Veraison.Value, b.Veraison.Value.AddDays(21)));
        }
        foreach (var l in Lots.Where(l => l.Red && l.FermentStart != null && l.FermentStart.Value >= Date.AddDays(-1)))
            if (!Tasks.Any(t => t.Kind == TaskKind.CapManagement && t.LotId == l.Id))
                newCap.Add(OpenTaskOn(TaskKind.CapManagement, l.BlockId, l.Id, l.FermentStart!.Value, l.FermentStart.Value.AddDays(2)));
        if (newLeaf.Count > 0) PostTaskMessage(TaskKind.LeafRemoval, newLeaf);
        if (newThin.Count > 0) PostTaskMessage(TaskKind.GreenHarvest, newThin);
        if (newCap.Count > 0) PostTaskMessage(TaskKind.CapManagement, newCap);
        foreach (var t in Tasks.Where(t => t.Status == TaskStatus.Open))
        {
            var b = Blocks.FirstOrDefault(x => x.Data.Id == t.BlockId);
            bool closed = Date >= t.Due
                || (t.Kind == TaskKind.Prune && b?.Budburst != null)
                || (t.Kind == TaskKind.GreenHarvest && (b!.Harvested || b.Picking));
            if (!closed) continue;
            t.Status = TaskStatus.Planned; t.Choice = TaskPlan(t); t.DecidedBy = "crew"; t.Decided = Date;
            bool pickedFirst = t.Kind == TaskKind.GreenHarvest && (b!.Harvested || b.Picking);
            if (!pickedFirst) t.CrewUntil = Date.AddDays(CrewDays(t) - 1);   // the crew does the work to the plan
        }
    }

    private FieldTask OpenTaskOn(TaskKind kind, string blockId, string lotId, DateOnly opened, DateOnly due)
    {
        var t = new FieldTask { Id = ++_taskId, Kind = kind, BlockId = blockId, LotId = lotId, Opened = opened, Due = due };
        Tasks.Add(t);
        return t;
    }

    private int CrewDays(FieldTask t)
    {
        if (t.Kind == TaskKind.CapManagement) return 1;
        var b = Blocks.First(x => x.Data.Id == t.BlockId);
        return (int)M.Clamp(Math.Ceiling(b.AreaHa * TaskCatalog.CrewHoursPerHa(t.Kind) / EconomyTables.CrewHoursPerDay(Ctx.Labour)), 1, 10);
    }

    /// <summary>Applies an option through the existing setting (no new physics).</summary>
    private void ApplyTaskOption(FieldTask t, string value, string timing)
    {
        var b = Blocks.FirstOrDefault(x => x.Data.Id == t.BlockId);
        switch (t.Kind)
        {
            case TaskKind.Prune: b!.BudLoad = Enum.Parse<BudLoad>(value); break;
            case TaskKind.LeafRemoval:
                b!.LeafSide = Enum.Parse<LeafRemovalSide>(value);
                b.LeafTiming = timing == "Late" ? LeafRemovalTiming.Late : LeafRemovalTiming.Early;
                break;
            case TaskKind.GreenHarvest:
                b!.CropThinning = Math.Clamp(int.Parse(value), 0, 2);
                if (b.Veraison != null && !b.Harvested) VineyardModel.ApplyCropThinning(b);
                break;
            case TaskKind.CapManagement:
                var lot = Lots.First(l => l.Id == t.LotId);
                lot.Choices["Cap management"] = Math.Clamp(int.Parse(value), 0, 3);
                break;
        }
    }

    private void Decide(FieldTask t, TaskStatus status, string value, string timing, string by)
    {
        ApplyTaskOption(t, value, timing);
        t.Status = status; t.Choice = value; t.Timing = timing; t.DecidedBy = by; t.Decided = Date;
        t.CrewUntil = Date.AddDays(CrewDays(t) - 1);
    }

    /// <summary>Command `task`: A = task id or "kind:Prune"; B = "do" | "delegate"; C = option value; D = timing ("Late"); E = "dashboard" when sent from the dashboard panel.</summary>
    private void TaskCommand(Command c)
    {
        var targets = c.A.StartsWith("kind:")
            ? Tasks.Where(t => t.Status == TaskStatus.Open && t.Kind.ToString() == c.A[5..]).ToList()
            : Tasks.Where(t => t.Status == TaskStatus.Open && t.Id.ToString() == c.A).ToList();
        foreach (var t in targets)
        {
            if (c.B == "delegate") Decide(t, TaskStatus.Delegated, TaskPlan(t), t.Kind == TaskKind.LeafRemoval ? Blocks.First(b => b.Data.Id == t.BlockId).LeafTiming.ToString() : "", "crew");
            else if (c.B == "do" && TaskCatalog.Options(t.Kind).Any(o => o.Value == c.C)) Decide(t, TaskStatus.Done, c.C, c.D, c.E == "dashboard" ? "dashboard" : "3d");
        }
    }

    /// <summary>A dashboard setting on a Block or Lot with an open task of the matching kind completes it.</summary>
    private void CompleteFromDashboard(TaskKind kind, string blockId, string lotId, string value, string timing)
    {
        var t = Tasks.FirstOrDefault(x => x.Status == TaskStatus.Open && x.Kind == kind && (lotId != "" ? x.LotId == lotId : x.BlockId == blockId));
        if (t == null) return;
        t.Status = TaskStatus.Done; t.Choice = value; t.Timing = timing; t.DecidedBy = "dashboard"; t.Decided = Date;
        t.CrewUntil = Date.AddDays(CrewDays(t) - 1);
    }

    private void PostTaskMessage(TaskKind kind, List<FieldTask> opened)
    {
        var first = opened[0];
        string blocks = string.Join(", ", opened.Select(t => kind == TaskKind.CapManagement ? $"Lot {t.LotId}" : $"Block {t.BlockId}"));
        string due = Dates.Short(first.Due);
        string plan = string.Join(", ", opened.Select(t => $"{(kind == TaskKind.CapManagement ? t.LotId : t.BlockId)}: {TaskCatalog.Label(kind, TaskPlan(t))}"));
        string role = kind == TaskKind.CapManagement ? "cellar" : kind == TaskKind.Prune && !MentorRetired ? "mentor" : "vineyard";
        (string subject, string body, string why, string msgKind) = kind switch
```

```csharp
    private static JsonArray TasksObj(GameSession g) => Arr(g.Tasks
        .Where(t => t.Status == TaskStatus.Open || t.CrewActive(g.Date))
        .OrderBy(t => t.Due).ThenBy(t => t.Id)
        .Select(t =>
        {
            string plan = g.TaskPlan(t);
            return (JsonNode)new JsonObject
            {
                ["id"] = t.Id, ["kind"] = t.Kind.ToString(), ["title"] = TaskCatalog.Title(t.Kind), ["verb"] = TaskCatalog.Verb(t.Kind),
                ["block"] = t.BlockId, ["lot"] = t.LotId, ["variety"] = g.Blocks.FirstOrDefault(b => b.Data.Id == t.BlockId)?.Variety.Name,
                ["status"] = t.Status.ToString(), ["opened"] = D(t.Opened), ["due"] = D(t.Due), ["daysLeft"] = t.Due.DayNumber - g.Date.DayNumber,
                ["plan"] = plan, ["planLabel"] = TaskCatalog.Label(t.Kind, plan), ["choice"] = t.Choice, ["timing"] = t.Timing, ["decidedBy"] = t.DecidedBy,
```
