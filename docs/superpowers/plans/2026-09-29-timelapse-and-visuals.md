# Time-lapse and visuals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A time-lapse in the 3D view over a physically based sky with day and night, plus textured variety-shaped leaves, bloomed bunches, living grass and one wind, all at ≥ 80 fps low-1 %.

**Architecture:** The sky becomes a procedural shader driven by vineyard.gd's existing sun maths; a `daytime` hour replaces the fixed afternoon and is animated by view3d.gd during the time-lapse, which asks the shell to advance the sim one day at a time. Leaves move from outline blades to textured cards generated by the Blender scripts; grass is a camera-following MultiMesh.

**Tech Stack:** Godot 4.7 GDScript + shaders, Blender 5.2 headless scripts, the C# sim unchanged.

**Spec:** `docs/superpowers/specs/2026-09-29-timelapse-and-visuals-design.md`

## Global Constraints

- Low-1 % frame rate ≥ 80 fps on every `--capture3d` vineyard/estate/hall view and during the time-lapse (owner's PC, display on).
- ADR 0001: the view never computes outcomes; time passes only through the shell's `advance`.
- Every in-game fact (leaf shapes) cited in `docs/science/`; looks labelled as look only.
- Build with `scripts/build-game.sh`; checks: sim tests, fuzz, tasktest, winerylook, worldtest, capture, screenshot review.
- Commits end with the Co-Authored-By line; push only when asked.

## Review Focus

1. **Time-lapse while an Alert fires** → stops, shows the subject, Space resumes, no day skipped. Pinned in Task 2 (`--timelapse` alert check).
2. **Leaving the 3D view during a time-lapse** → time stops, the 2D screens rebuild with the current day. Pinned in Task 2.
3. **Night in the hall and cellar** → interior lights unaffected; outside darkens; winery windows glow. Pinned in Task 1 shots.
4. **Weeks speed on a heavy Plot (Mosel Blauschiefer)** → no frame below the floor for more than a blip. Pinned in Task 2 (frame-time log).
5. **Old saves / no time-lapse used** → the static view looks like a good afternoon (hour as today). Pinned in Task 1 (`--capture3d` shots unchanged in framing).
